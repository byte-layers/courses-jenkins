---
title: "Démarrer une stack Jenkins décrite par du code"
description: "Récupérer la stack, générer ses secrets, la démarrer, déclarer le second agent dans JCasC, puis cloner PetClinic depuis Gitea"
---

Dans ce chapitre, vous démarrez la stack du lab et vous lisez comment elle se configure toute seule. Vous la récupérez et générez ses mots de passe, vous la démarrez, puis vous constatez qu'un agent manque et vous le déclarez vous-même dans la configuration de Jenkins. Vous terminez en clonant PetClinic depuis Gitea, prêt pour le premier `Jenkinsfile`.

Comptez environ 45 minutes, dont une dizaine pour les téléchargements.
